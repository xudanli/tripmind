# 组件关系结构文档

本文档详细说明 AI Travel Companion 应用中页面组件和业务组件之间的层级关系、数据流和通信方式。

## 一、整体架构

```
App.vue (根组件)
├── RouterView
    ├── LoginView (登录页)
    ├── HomeView (首页)
    ├── PlannerView (行程规划页)
    ├── TravelListView (行程列表页)
    ├── TravelDetailView (行程详情页) ⭐ 核心页面
    └── AcceptInvitationView (接受邀请页)
```

## 二、主要页面视图（Views）

### 1. TravelDetailView（行程详情页）

**路径**：`src/views/TravelDetailView.vue`  
**路由**：`/travel/:id`  
**职责**：行程详情页的主容器，协调所有子组件

**组件层级结构**：
```
TravelDetailView
├── ItinerarySkeleton (加载骨架屏)
├── TravelDetailHeader (详情页头部)
├── Main Content Area
│   ├── ExperienceDay (体验日组件) ⭐ 核心组件
│   └── Sidebar Panel
│       ├── TravelSidebar (侧边栏容器)
│       ├── VisaGuide (签证指引)
│       ├── SafetyNoticeCard (安全提示)
│       ├── PracticalInfoCard (实用信息)
│       ├── LocalEssentialsCard (本地实用信息)
│       └── CulturalGuideCard (文化红黑榜)
└── TravelAssistant (AI旅行助手 - 浮动组件)
```

**主要子组件**：
- `ExperienceDay` - 行程体验日展示（核心）
- `TravelSidebar` - 侧边栏（包含多个 Tab）
- `TravelDetailHeader` - 页面头部
- `VisaGuide` - 签证指引
- `SafetyNoticeCard` - 安全提示卡片
- `PracticalInfoCard` - 实用信息卡片
- `LocalEssentialsCard` - 本地实用信息卡片
- `CulturalGuideCard` - 文化红黑榜卡片
- `TravelAssistant` - AI 旅行助手（浮动窗口）

### 2. PlannerView（行程规划页）

**路径**：`src/views/PlannerView.vue`  
**路由**：`/planner`  
**职责**：用户创建新行程的表单页面

**组件层级结构**：
```
PlannerView

        ├── Travelers Input (旅行者数量)
```

### 3. TravelListView（行程列表页）

**路径**：`src/views/TravelListView.vue`

**职责**：显示用户的所有行程列表

**组件层级结构**：

## 五、数据流和通信方式

### 1. Props 传递（父 → 子）

**TravelDetailView → ExperienceDay**
```typescript
<ExperienceDay 
  :travel="travel" 
  @update="handleTravelUpdate" 
  @refresh="handleTravelRefresh" 
/>
```

**ExperienceDay → TimeSlotCard**
```typescript
<TimeSlotCard
  :day="day"
  :slot="slot"
  :currency="currency"
  :platform="platform"
  :expanded="expanded"
  @edit="slotEditing.openEdit"
  @remove="handleDeleteSlot"
/>
```

**TravelSidebar → DiscussionArea**
```typescript
<DiscussionArea :travel-id="travelId" />
```

### 2. Events 通信（子 → 父）

**ExperienceDay → TravelDetailView**
- `@update` - 行程数据更新
- `@refresh` - 刷新行程数据

**TimeSlotCard → ExperienceDay**
- `@edit` - 编辑活动
- `@remove` - 删除活动
- `@search` - 搜索 POI
- `@book` - 预订活动
- `@add-nearby-attraction` - 添加附近景点

**DiscussionArea → TravelSidebar**
- 通过 `travelId` prop 直接调用 API，不向上传递事件

### 3. Store 状态管理

**使用的 Stores**：
- `useTravelListStore` - 行程列表状态
- `useTravelStore` - 行程详情状态
- `useI18nStore` - 国际化状态
- `useUserStore` - 用户状态

**数据流**：
```
API 调用
  ↓
Store 更新
  ↓
组件响应式更新
```

### 4. Composables（组合式函数）

**ExperienceDay 使用的 Composables**：
- `useSlotEditing` - 管理活动编辑状态和逻辑
- `usePoiSearch` - 管理 POI 搜索状态和逻辑
- `useSlotFormatting` - 格式化活动信息
- `useMapNavigation` - 处理地图导航
- `useSlotActions` - 处理活动操作（删除、添加等）
- `useItineraryModals` - 管理模态框显示状态
- `useAutoGeocode` - 自动地理编码

**TravelDetailView 使用的 Composables**：
- `useItineraryData` - 管理行程数据加载和状态

## 七、组件通信模式

### 1. 父子组件通信

**Props Down, Events Up**
```typescript
// 父组件传递数据
<ChildComponent :data="parentData" @update="handleUpdate" />

// 子组件接收和触发
const props = defineProps<{ data: any }>()
const emit = defineEmits<{ update: [value: any] }>()
```

### 2. 跨组件通信

**使用 Store**
```typescript
// 组件 A
const travelListStore = useTravelListStore()
travelListStore.updateTravel(travelData)

// 组件 B
const travelListStore = useTravelListStore()
const travel = computed(() => travelListStore.currentTravel)
```

### 3. 全局事件

**使用 window 事件**
```typescript
// 触发事件
window.dispatchEvent(new Event('userProfileUpdated'))

// 监听事件
window.addEventListener('userProfileUpdated', handler)
```

## 十、组件开发规范

### 1. 命名规范

- **Views**：`*View.vue`（如 `TravelDetailView.vue`）
- **Components**：PascalCase（如 `TimeSlotCard.vue`）
- **Composables**：`use*`（如 `useSlotEditing.ts`）

### 2. 文件组织

```
src/
├── views/           # 页面级组件
├── components/      # 业务组件
│   └── TravelDetail/
│       ├── ExperienceDay/
│       │   ├── TimeSlotCard.vue
│       │   ├── SlotHero.vue
│       │   └── ...
│       └── DiscussionArea/
│           ├── MessageGroup.vue
│           └── ...
├── composables/     # 组合式函数
└── stores/          # 状态管理
```

### 3. Props 定义

```typescript
// 推荐：使用 interface 定义 Props
interface Props {
  travelId: string
  mode?: 'planner' | 'seeker' | 'inspiration'
}

const props = defineProps<Props>()
```

### 4. Events 定义

```typescript
// 推荐：使用类型定义 Events
const emit = defineEmits<{
  update: [value: any]
  refresh: []
  delete: [id: string]
}>()
```

## 十二、性能优化建议

### 1. 组件懒加载

```typescript
// 模态框组件使用动态导入
const SlotEditModal = defineAsyncComponent(() => 
  import('./SlotEditModal.vue')
)
```

### 2. 列表虚拟滚动

对于大量活动的列表，建议使用虚拟滚动（如 `vue-virtual-scroller`）

### 3. 图片懒加载

使用 `AppImage` 组件自动处理图片懒加载

### 4. 计算属性缓存

使用 `computed` 缓存复杂计算，避免重复计算

## 十三、扩展指南

### 添加新功能组件

1. 在 `src/components/TravelDetail/` 下创建新组件
2. 在 `TravelDetailView.vue` 或相应父组件中引入
3. 通过 Props 传递必要数据
4. 通过 Events 向上传递操作

### 添加新页面

1. 在 `src/views/` 下创建新视图组件
2. 在 `src/router/index.ts` 中添加路由
3. 在 `App.vue` 的 `RouterView` 中自动渲染
