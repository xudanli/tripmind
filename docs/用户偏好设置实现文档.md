# 用户偏好设置实现文档

本文档详细说明用户偏好设置的内容、相关接口和实现方式。

## 一、用户偏好设置内容

用户偏好设置包含以下内容（定义在 `src/config/userProfile.ts`）：

### 1. 语言与显示设置
- **界面语言** (`interfaceLanguage`)
  - 类型：`string`
  - 可选值：`'zh-CN'`（中文）、`'en-US'`（英语）
  - 用途：控制应用界面显示的语言
  - 默认值：`'zh-CN'`

### 2. 身份信息
- **我的国籍** (`nationality`)
  - 类型：`{ country: string, countryCode: string } | null`
  - 用途：用于判断前往目的地是否需要签证
  - 使用场景：签证信息查询接口

- **永久居民身份** (`permanentResidency`)
  - 类型：`{ country: string, countryCode: string } | null`
  - 用途：考虑永久居民身份（如绿卡、永久居留权）在签证判断中的作用
  - 使用场景：签证信息查询接口

- **已持有的签证** (`heldVisas`)
  - 类型：`string[]`（国家代码数组）
  - 用途：已持有有效签证的国家列表，用于推荐目的地时给予最高优先级
  - 使用场景：目的地推荐、签证分析

### 3. 地理信息
- **我所在国家** (`location`)
  - 类型：`{ country: string, countryCode: string } | null`
  - 用途：用于在未指定目的地时优先推荐该国家或附近地区的目的地
  - 使用场景：目的地推荐、行程生成

### 4. 语言能力
- **精通的语言** (`proficientLanguages`)
  - 类型：`string[]`（语言代码数组）
  - 可选值：支持 15 种语言（中文、英语、日语、韩语、法语、德语、西班牙语、意大利语、葡萄牙语、俄语、阿拉伯语、泰语、越南语、印尼语、印地语）
  - 用途：根据用户语言偏好调整显示格式和内容
  - 默认值：`['zh-CN']`

### 5. 货币偏好
- **偏好货币** (`preferredCurrency`)
  - 类型：`string`（ISO 4217 货币代码）
  - 用途：用于显示费用和价格信息
  - 默认值：`'CNY'`（人民币）
  - 使用场景：行程费用显示、活动费用格式化

### 6. 交通方式偏好
- **默认交通方式** (`preferredTransportMode`)
  - 类型：`'public_transit_and_walking' | 'driving_and_walking'`
  - 可选值：
    - `'public_transit_and_walking'`：公共交通 + 短距离步行
    - `'driving_and_walking'`：驾车 + 短距离步行
  - 用途：在生成行程时推荐相应的交通方式
  - 默认值：`'public_transit_and_walking'`
  - 使用场景：行程生成接口

## 二、相关接口

### 1. 用户偏好设置 API

#### 1.1 获取用户偏好设置
- **接口路径**：`GET /api/user/preferences`
- **认证方式**：Cookie 认证（`credentials: 'include'`）
- **实现文件**：`src/services/userPreferencesAPI.ts`
- **函数**：`getUserPreferences()`
- **响应格式**：
  ```typescript
  {
    preferences: Record<string, any>  // 用户偏好设置对象
  }
  ```
- **使用场景**：
  - 应用启动时同步服务器偏好设置（`App.vue` 的 `syncPreferencesFromServer`）
  - 用户登录后加载偏好设置

#### 1.2 更新用户偏好设置
- **接口路径**：`PUT /api/user/preferences`
- **认证方式**：Cookie 认证（`credentials: 'include'`）
- **实现文件**：`src/services/userPreferencesAPI.ts`
- **函数**：`updateUserPreferences(preferences: Record<string, any>)`
- **请求格式**：
  ```typescript
  {
    preferences: UserProfileConfig  // 完整的用户偏好设置对象
  }
  ```
- **使用场景**：
  - 用户在偏好设置弹窗中保存设置时（`App.vue` 的 `handleUserProfileSave`）

### 2. 使用用户偏好的接口

#### 2.1 签证信息查询接口
- **接口路径**：`GET /api/v1/visa/info`
- **实现文件**：`src/services/visaAPI.ts`
- **使用的偏好**：
  - `nationality`（国籍）→ `nationalityCode`
  - `permanentResidency`（永久居民身份）→ `permanentResidencyCode`
- **使用函数**：
  - `getUserNationalityCode()` - 获取用户国籍代码
  - `getUserPermanentResidencyCode()` - 获取永久居民身份代码
- **使用场景**：
  - 查询前往特定目的地是否需要签证
  - 多目的地签证分析

#### 2.2 行程生成接口
- **接口路径**：`POST /api/v1/journeys/generate`
- **实现文件**：`src/services/itineraryAPI.ts`
- **使用的偏好**：
  - `preferredTransportMode`（交通方式偏好）→ 在请求的 `preferences` 中传递
  - `location`（所在国家）→ 用于推荐目的地
  - `proficientLanguages`（精通语言）→ 可能用于内容本地化
- **使用函数**：
  - `getUserTransportPreference()` - 获取交通方式偏好
  - `getUserLocationCode()` - 获取所在国家代码
- **使用场景**：
  - Planner 模式生成行程时
  - 根据用户偏好调整行程风格和交通方式

#### 2.3 费用显示相关
- **使用的偏好**：
  - `preferredCurrency`（货币偏好）
- **使用函数**：
  - `getUserPreferredCurrency()` - 获取用户货币偏好
- **使用场景**：
  - 格式化活动费用显示（`useSlotFormatting.ts`）
  - 行程总费用显示
  - 预算管理界面

#### 2.4 目的地推荐
- **使用的偏好**：
  - `location`（所在国家）→ 优先推荐附近目的地
  - `heldVisas`（已持有签证）→ 优先推荐已持有签证的国家
- **使用函数**：
  - `getUserLocationCode()` - 获取所在国家代码
  - `getHeldVisas()` - 获取已持有签证列表
- **使用场景**：
  - 灵感模式自动推荐目的地
  - 未指定目的地时的智能推荐

## 三、实现方式

### 1. 数据存储

#### 1.1 本地存储（localStorage）
- **存储键**：`'user_profile'`
- **存储格式**：JSON 字符串
- **实现函数**：
  - `getUserProfile()` - 从 localStorage 读取
  - `setUserProfile(config)` - 保存到 localStorage
  - `getUserProfileOrDefault()` - 获取或创建默认配置
- **位置**：`src/config/userProfile.ts`

#### 1.2 服务器同步
- **同步时机**：
  - 应用启动时（`App.vue` 的 `onMounted` 中调用 `syncPreferencesFromServer`）
  - 用户保存偏好设置时（`handleUserProfileSave` 中调用 `updateUserPreferences`）
- **同步策略**：
  - 优先使用服务器数据（如果登录）
  - 如果服务器同步失败，使用本地缓存
  - 保存时先保存到本地，再同步到服务器

### 2. 数据流

```
用户操作
  ↓
App.vue (handleUserProfileSave)
  ↓
1. 保存到 localStorage (setUserProfile)
  ↓
2. 同步到服务器 (updateUserPreferences)
  ↓
3. 触发事件 (window.dispatchEvent('userProfileUpdated'))
  ↓
其他组件响应更新
```

### 3. 偏好设置的使用流程

#### 3.1 读取偏好设置
```typescript
// 方式1：直接读取（从 localStorage）
import { getUserProfile } from '@/config/userProfile'
const profile = getUserProfile()

// 方式2：使用工具函数（带默认值）
import { getUserNationalityCode, getUserPreferredCurrency } from '@/config/userProfile'
const nationality = getUserNationalityCode()  // 返回 string | null
const currency = getUserPreferredCurrency()   // 返回 string（默认 'CNY'）
```

#### 3.2 在接口调用中使用
```typescript
// 示例：签证信息查询
import { getUserNationalityCode, getUserPermanentResidencyCode } from '@/config/userProfile'
import { getVisaInfo } from '@/services/visaAPI'

const nationalityCode = getUserNationalityCode()
const permanentResidencyCode = getUserPermanentResidencyCode()

const visaInfo = await getVisaInfo({
  destinationCountry: 'US',
  nationalityCode,
  permanentResidencyCode
})
```

#### 3.3 在组件中使用
```typescript
// 示例：格式化费用显示
import { getUserPreferredCurrency } from '@/config/userProfile'
import { formatCurrency } from '@/utils/currency'

const currencyCode = getUserPreferredCurrency()
const formattedCost = formatCurrency(100, getCurrencyByCode(currencyCode))
```

### 4. 响应式更新

#### 4.1 界面语言更新
- 保存时立即更新：`i18nStore.setLocale(selectedInterfaceLanguage.value)`
- 同步时自动应用：`syncPreferencesFromServer` 中会设置语言

#### 4.2 全局事件通知
- 保存成功后触发：`window.dispatchEvent(new Event('userProfileUpdated'))`
- 其他组件可以监听此事件并更新相关显示

### 5. 错误处理

#### 5.1 服务器同步失败
- 如果服务器同步失败，设置仍会保存到本地
- 显示警告消息：`'设置已在本地保存，但同步服务器失败，请稍后重试。'`
- 不会阻止用户继续使用应用

#### 5.2 数据验证
- 使用 `validateUserProfile()` 验证配置格式
- 如果验证失败，使用默认配置
- 确保数据类型和结构正确

## 五、使用示例

### 示例1：在行程生成中使用交通方式偏好
```typescript
import { getUserTransportPreference } from '@/config/userProfile'
import { generateItinerary } from '@/services/itineraryAPI'

const transportMode = getUserTransportPreference()  // 'public_transit_and_walking' | 'driving_and_walking'

const result = await generateItinerary({
  destination: '日本',
  days: 5,
  startDate: '2024-06-01',
  preferences: {
    interests: ['自然风光'],
    budget: 'medium',
    travelStyle: 'moderate',
    transportMode  // 传递交通方式偏好
  }
})
```

### 示例2：在签证查询中使用国籍信息
```typescript
import { getUserNationalityCode, getUserPermanentResidencyCode } from '@/config/userProfile'
import { getVisaInfo } from '@/services/visaAPI'

const nationalityCode = getUserNationalityCode()
const permanentResidencyCode = getUserPermanentResidencyCode()

if (nationalityCode) {
  const visaInfo = await getVisaInfo({
    destinationCountry: 'US',
    nationalityCode,
    permanentResidencyCode: permanentResidencyCode || undefined
  })
  console.log('是否需要签证:', visaInfo.requiresVisa)
}
```

### 示例3：格式化费用显示
```typescript
import { getUserPreferredCurrency } from '@/config/userProfile'
import { formatCurrency, getCurrencyByCode } from '@/utils/currency'

const currencyCode = getUserPreferredCurrency()  // 'CNY' | 'USD' | 'EUR' 等
const currency = getCurrencyByCode(currencyCode)
const formatted = formatCurrency(1000, currency)  // '¥1,000' 或 '$1,000' 等
```

## 六、注意事项

1. **数据同步**：
   - 用户偏好设置同时存储在本地（localStorage）和服务器
   - 优先使用服务器数据（如果登录）
   - 未登录时仅使用本地数据

2. **默认值**：
   - 所有偏好设置都有合理的默认值
   - 如果用户未设置，系统会使用默认值继续工作

3. **类型安全**：
   - 使用 TypeScript 类型定义确保类型安全
   - 使用 `validateUserProfile()` 验证数据格式

4. **向后兼容**：
   - 偏好设置字段都是可选的
   - 旧版本数据可以平滑升级

5. **性能考虑**：
   - 偏好设置存储在 localStorage，读取速度快
   - 服务器同步是异步的，不会阻塞 UI
