# Planner 和 Seeker 模式输入信息文档

本文档详细说明 Planner 模式和 Seeker 模式在创建页面中收集的所有用户输入信息。

---

## 📋 Planner 模式输入信息

Planner 模式采用分步骤表单，共 5 个步骤（包含确认页）。

### 数据结构

```typescript
interface PlannerFormData {
  destination: string          // 目的地（必填）
  duration: number             // 行程天数（必填）
  budget: string               // 预算范围（必填）
  preferences: string[]        // 偏好（必填，多选）
  travelStyle: string          // 旅行节奏（必填）
  customRequirements?: string  // 自定义要求（可选）
}
```

### 步骤 1：目的地选择 ✈️

**字段名：** `destination`

**输入类型：** 文本输入框（Text Input）

**是否必填：** ✅ 是

**说明：** 用户输入想要前往的旅行目的地

**示例值：**
- "日本"
- "巴黎"
- "马尔代夫"
- "冰岛"

---

### 步骤 2：时长选择 📅

**字段名：** `duration`

**输入类型：** 下拉选择（Select）

**是否必填：** ✅ 是

**可选值：**
- `1` - 1 天
- `2` - 2 天
- `3` - 3 天
- `4` - 4 天
- `5` - 5 天
- `6` - 6 天
- `7` - 7 天
- `10` - 10 天
- `14` - 14 天
- `21` - 21 天
- `30` - 30 天

**说明：** 用户选择行程的总天数

---

### 步骤 3：预算选择 💰

**字段名：** `budget`

**输入类型：** 下拉选择（Select）

**是否必填：** ✅ 是

**可选值：**
- `economy` - 经济型
  - 描述：预算有限，追求性价比
- `comfort` - 舒适型
  - 描述：中等预算，追求舒适体验
- `luxury` - 豪华型
  - 描述：预算充足，追求高品质体验

**说明：** 预算选项会根据目的地动态调整（如果已选择目的地）

---

### 步骤 4：偏好选择 🎯

#### 4.1 旅行偏好（多选）

**字段名：** `preferences`

**输入类型：** 多选下拉（Multi-Select）

**是否必填：** ✅ 是（至少选择一项）

**可选值：**
- `culture` - 🏛️ 文化探索
- `food` - 🍜 美食体验
- `nature` - 🌲 自然风光
- `shopping` - 🛍️ 购物休闲
- `adventure` - 🏔️ 冒险体验
- `relaxation` - 🏖️ 休闲放松

**说明：** 用户可以选择多个偏好，系统会根据偏好推荐相关活动

#### 4.2 旅行节奏

**字段名：** `travelStyle`

**输入类型：** 下拉选择（Select）

**是否必填：** ✅ 是

**可选值：**
- `fast` - 紧凑型
  - 描述：行程紧凑，高效利用时间
- `moderate` - 平衡型
  - 描述：节奏适中，兼顾效率与体验
- `slow` - 慢节奏
  - 描述：节奏舒缓，深度体验

**说明：** 控制行程的节奏和活动密度

#### 4.3 自定义要求（可选）

**字段名：** `customRequirements`

**输入类型：** 多行文本域（Textarea）

**是否必填：** ❌ 否

**限制：**
- 最大长度：600 字符
- 显示字符计数

**占位符提示：** "请描述您的特殊要求或期望，例如：想要看日出、避开人多的地方、体验当地文化等…"

**说明：** 用户可以补充任何特殊需求或期望

---

### 步骤 5：确认页面 🎉

**显示内容：**
- 目的地
- 时长
- 预算
- 偏好（以标签形式显示）
- 节奏

**操作：** 用户确认后提交，系统生成行程

---

## 💗 Seeker 模式输入信息

Seeker 模式采用卡片式选择界面，共 5 个步骤（包含推荐结果页）。

### 数据结构

```typescript
interface MoodData {
  currentMood: string        // 当前心情（必填）
  desiredExperience: string  // 期望体验（必填）
  budget: string             // 预算范围（必填）
  duration: string           // 时长类型（必填）
}
```

### 步骤 1：心情选择 💭

**字段名：** `currentMood`

**输入类型：** 单选卡片（Card Selection）

**是否必填：** ✅ 是

**可选值：**
- `calm` - 😌 平静放松
  - 描述：逃离喧嚣，寻找内心平静
- `active` - ⚡ 充满活力
  - 描述：精力充沛，想要探索世界
- `romantic` - 💕 浪漫温馨
  - 描述：寻求浪漫，体验甜蜜
- `adventurous` - 🗻 冒险刺激
  - 描述：追求刺激，挑战自我
- `cultural` - 🏛️ 文化探索
  - 描述：深入了解不同文化

**说明：** 用户选择最能描述当前心情的状态

---

### 步骤 2：体验选择 🌅

**字段名：** `desiredExperience`

**输入类型：** 单选卡片（Card Selection）

**是否必填：** ✅ 是

**可选值：**
- `sightseeing` - 🏛️ 观光游览
  - 描述：参观著名景点，感受历史
- `nature` - 🌲 自然风光
  - 描述：亲近自然，享受美景
- `food` - 🍜 美食探索
  - 描述：品尝当地美食，体验文化
- `shopping` - 🛍️ 购物
  - 描述：购买纪念品和特产
- `nightlife` - 🌃 夜生活
  - 描述：体验当地夜生活
- `adventure` - 🏄 冒险活动
  - 描述：尝试刺激的户外活动

**说明：** 用户选择最想在此次旅行中体验的内容

---

### 步骤 3：预算选择 💰

**字段名：** `budget`

**输入类型：** 单选卡片（Card Selection）

**是否必填：** ✅ 是

**可选值：**
- `economy` - 💵 经济型
  - 描述：预算有限，追求性价比
- `comfort` - ⭐ 舒适型
  - 描述：中等预算，追求舒适体验
- `luxury` - 💎 豪华型
  - 描述：预算充足，追求高品质体验

**说明：** 用户选择适合的预算范围

---

### 步骤 4：时长选择 ⏰

**字段名：** `duration`

**输入类型：** 单选卡片（Card Selection）

**是否必填：** ✅ 是

**可选值：**
- `weekend` - 🏃‍♀️ 周末短途
  - 描述：2-3 天的短途旅行
- `week` - 🚶‍♀️ 一周左右
  - 描述：5-7 天的中等时长旅行
- `extended` - 🐌 深度慢游
  - 描述：10 天以上的深度旅行

**说明：** 用户选择期望的旅行时长类型

---

### 步骤 5：推荐结果 🌸

**显示内容：**
- AI 旅行心伴的推荐消息
- 推荐目的地
- 推荐行程概览（天数、每日主题）

**操作：** 用户可以查看详情并创建旅程

---

## 📊 数据对比

| 字段 | Planner 模式 | Seeker 模式 |
|------|-------------|------------|
| **目的地** | ✅ 文本输入 | ❌ 不收集（由 AI 推荐） |
| **时长** | ✅ 具体天数（1-30天） | ✅ 时长类型（周末/一周/深度） |
| **预算** | ✅ 下拉选择 | ✅ 卡片选择 |
| **偏好/体验** | ✅ 多选偏好 | ✅ 单选体验 |
| **节奏** | ✅ 旅行节奏 | ❌ 不收集 |
| **自定义要求** | ✅ 可选文本域 | ❌ 不收集 |
| **心情状态** | ❌ 不收集 | ✅ 当前心情 |

## 🔄 数据流转

### Planner 模式
```
用户输入 → PlannerFormData → generateItinerary('planner') → 生成行程 → 创建 Travel
```

### Seeker 模式
```
用户输入 → MoodData → generateItinerary('seeker') → AI 推荐 → 创建 Travel
```

---

## 📝 注意事项

1. **Planner 模式** 需要用户明确知道目的地，适合有明确旅行计划的用户
2. **Seeker 模式** 不需要目的地，AI 会根据心情和偏好推荐，适合随性而行的用户
3. 所有必填字段都有前端验证，确保数据完整性
4. 预算选项会根据已选择的目的地动态调整（Planner 模式）
5. 自定义要求字段（Planner 模式）最多 600 字符，支持特殊需求补充

---

## 🎯 使用场景

### Planner 模式适合：
- 有明确目的地的用户
- 需要详细行程规划的用户
- 追求高效、精准规划的用户

### Seeker 模式适合：
- 不确定目的地的用户
- 根据心情选择旅行的用户
- 追求治愈、放松体验的用户
